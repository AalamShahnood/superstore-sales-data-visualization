# Superstore Sales Data Visualization & Business Insights

## Project Overview
This project analyzes Superstore sales data using Python to identify sales trends, category performance, regional profitability, and loss-making product sub-categories.

## Objectives
- Analyze monthly sales trends.
- Compare sales across product categories.
- Evaluate profit across regions.
- Identify loss-making product sub-categories.
- Present actionable business recommendations.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Key Results
- **Total Sales:** 2,297,200.86
- **Total Profit:** 286,397.02
- **Highest Sales Month:** November 2018
- **Top Sales Category:** Technology
- **Most Profitable Region:** West
- **Largest Loss-Making Sub-Category:** Tables

## Files Included
- `Superstore_Data_Visualization.ipynb` — analysis code and visualizations
- `Superstore_Final_Dashboard.png` — dashboard
- `Superstore_Sales_Visualization_Report.pdf` — project report

## Conclusion
The project demonstrates how data visualization can reveal sales patterns, highlight profitable regions and categories, and identify products requiring further investigation.
